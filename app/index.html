        How to read the flags

        • Possibly missable — a step that may only be doable at one point in the story; do it when the roadmap says so.
        • Watch — a one-chance moment in free roam; easy to walk past, so attempt it when you are there.
        • Unconfirmed — the official description gives no clear trigger and only one source describes it; treat it as a lead, not a fact.
        • Sources disagree — guides do not agree; both versions are shown so you can judge for yourself.
        • Single-source — only one of the seven sources covers this trophy.
